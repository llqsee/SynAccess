# Data Upload

This page will contain detailed information about MAVIS's data upload capabilities.

## Supported Formats

- CSV files
- Excel files (.xlsx, .xls)
- JSON files

## File Size Limits

- Maximum file size: 100MB per file
- Recommended: Clean, preprocessed data

## Data Requirements

- Both real and synthetic datasets should have the same column structure
- Supported data types: numeric, categorical, datetime
- Missing values are handled automatically
