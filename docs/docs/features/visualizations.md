# Interactive Visualizations

MAVIS provides powerful interactive visualization capabilities for exploring synthetic data.

## Scatter Plot Features

- **Zoom and Pan**: Navigate through the embedding space
- **Point Selection**: Click and drag to select data subsets
- **Hover Information**: See original data values on hover
- **Legend Toggle**: Show/hide real vs synthetic datasets

## Distribution Analysis

- **Histograms**: For continuous variables
- **Violin Plots**: For distribution shape analysis
- **Bar Charts**: For categorical variables
- **Statistical Overlays**: Mean, median, quartiles

## Interactive Controls

- **Variable Selection**: Dropdown for quick switching
- **Chart Type Toggle**: Switch between visualization types
- **Scale Options**: Linear vs logarithmic scaling
